# Установка на iPhone без Mac

Идея: приложение собирает бесплатный облачный Mac (GitHub Actions), вы скачиваете готовый файл
`ymusic.ipa` и ставите его на iPhone с Windows программой Sideloadly.

Ограничения (из-за бесплатного Apple ID): приложение работает **7 дней**, потом его нужно поставить заново
(данные и токен сохраняются, если не удалять приложение). Фоновое воспроизведение при заблокированном экране
включено в настройках, но не проверялось.

Это первая iOS-сборка проекта: возможны мелкие ошибки компиляции. Если сборка в GitHub упадет, пришлите мне
последние строки красного лога.

---

## Часть 1. Выложить проект на GitHub

1. Зарегистрируйтесь на https://github.com (если нет аккаунта).
2. Создайте новый репозиторий: https://github.com/new
   - Имя: `ymusic`
   - Видимость: **Public** (для публичных репозиториев облачная сборка бесплатна; в коде нет ваших паролей и
     токенов, токен вы вводите уже в самом приложении). В приватном репозитории минуты сборки на macOS
     расходуются заметно быстрее, лимит бесплатного тарифа - 2000 "обычных" минут в месяц.
   - Остальные галочки не ставьте.
3. Распакуйте новый архив поверх `C:\dev\ymusic_app` (с заменой файлов): в нем добавились папка `.github`
   и файл `tools\icon_ios_1024.png`.
4. В PowerShell:

```
cd C:\dev\ymusic_app
git config user.name "ВАШЕ_ИМЯ"
git config user.email "ваша_почта@example.com"
git init
git add .
git commit -m "Initial"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ymusic.git
git push -u origin main
```

При первой отправке откроется окно браузера для входа в GitHub - войдите и разрешите доступ.

## Часть 2. Собрать IPA в облаке

1. Откройте ваш репозиторий на GitHub → вкладка **Actions**.
2. Если GitHub просит включить workflows - нажмите кнопку подтверждения.
3. Слева выберите **Build iOS (unsigned IPA)** → справа **Run workflow** → зеленая кнопка **Run workflow**.
4. Подождите 10-20 минут. Зеленая галочка = успех.
5. Откройте завершенный запуск, внизу в разделе **Artifacts** скачайте `ymusic-ipa`. Распакуйте zip, внутри
   файл `ymusic.ipa`.

Если запуск красный: откройте его, нажмите на упавший шаг и пришлите мне последние ~30 строк лога.

## Часть 3. Поставить на iPhone (Sideloadly)

Что нужно на компьютере:
- **iTunes от Apple** с https://www.apple.com/itunes/ (версия из **Microsoft Store не подойдет**).
- **Sideloadly**: https://sideloadly.io
- Apple ID, который уже хотя бы раз входил на каком-либо iPhone/iPad (совсем новый не подойдет).
  Пароль вы вводите в стороннюю программу, поэтому при желании заведите отдельный Apple ID для этого.

Шаги:
1. Подключите iPhone кабелем, на телефоне нажмите «Доверять этому компьютеру».
2. Откройте Sideloadly, выберите iPhone в поле устройства, введите Apple ID.
3. Перетащите `ymusic.ipa` в окно Sideloadly и нажмите **Start**, введите пароль Apple ID (при двухфакторной
   защите потом - код).
4. После установки на iPhone:
   - Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).
   - Настройки → Основные → **VPN и управление устройством** → ваш Apple ID → **Доверять**.
5. Запустите «Моя Музыка» с домашнего экрана и войдите по токену (как в Windows-версии).

Через 7 дней приложение перестанет открываться: подключите телефон и повторите шаг 3 (приложение
не удаляйте).

## Что работает на iPhone в этой версии
Вход по токену, вкладки (волна, любимое, плейлисты, поиск), плеер. Не сделаны: управление с экрана
блокировки и из шторки, Spotify/SoundCloud.
