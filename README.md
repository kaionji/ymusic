# Моя Музыка - неофициальный клиент Яндекс Музыки (iOS + Windows)

Свой интерфейс, а каталог, плейлисты, поиск и аудио приходят из вашего аккаунта Яндекс Музыки.
Стек: Flutter (один код на Windows и iOS), плеер media_kit (умеет HLS).

Что умеет: вход по токену, **Моя волна**, "Мне нравится", ваши плейлисты, поиск треков, плеер
(пауза, перемотка, следующий/предыдущий, очередь, **перемешать, повтор, лайк, громкость**).
Стиль (сейчас чёрный и серый) меняется в одном файле: `lib/theme.dart`. Иконка - полумесяц (`tools/app_icon.ico`).

Горячие клавиши (когда окно приложения активно): мультимедийные клавиши клавиатуры (пауза, следующий,
предыдущий), `Ctrl+Пробел` - пауза, `Alt+→` / `Alt+←` - следующий/предыдущий трек.

> Проект не тестировался на реальном устройстве: код написан по описанию неофициального API.
> Если что-то не заработает, пришлите текст ошибки - поправим.

## Часть 1. Windows

### 1. Установите инструменты
1. **Git**: https://git-scm.com/download/win
2. **Flutter SDK** (последний stable). Страница установки: https://docs.flutter.dev/install/manual
   Проще всего через Git (PowerShell):
   `git clone https://github.com/flutter/flutter.git -b stable C:\src\flutter`
   затем добавьте `C:\src\flutter\bin` в PATH:
   `[Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";C:\src\flutter\bin", "User")`
   и откройте новое окно PowerShell.
3. **Visual Studio 2022 Community** (не VS Code!) с рабочей нагрузкой
   **"Разработка классических приложений на C++"** (Desktop development with C++).
4. Включите **режим разработчика** Windows (нужен для плагинов): откройте PowerShell и выполните
   `start ms-settings:developers`, включите переключатель.
5. Проверьте: `flutter doctor` - для Windows должны быть зеленые галочки.

### 2. Подготовьте проект
Распакуйте архив в папку без пробелов и кириллицы в пути, например `C:\dev\ymusic_app`, затем:

```
cd C:\dev\ymusic_app
flutter create --platforms=windows,ios .
rmdir /s /q test
flutter pub get
```

`flutter create .` добавит папки `windows/` и `ios/`; ваши `lib/` и `pubspec.yaml` не перезапишутся.
(Если папки `test` нет, команда `rmdir` просто выдаст ошибку - это нормально.)

### 3. Запуск
```
flutter run -d windows
```
Первая сборка долгая (несколько минут). Готовое приложение: `flutter build windows` →
`build\windows\x64\runner\Release\`.

### 4. Установить как обычное приложение (ярлык на рабочем столе и в Пуск)
В папке проекта выполните в PowerShell:

```
powershell -ExecutionPolicy Bypass -File .\install_windows.ps1
```

Скрипт сам: переименует окно в "Моя Музыка", поставит иконку, соберет релизную версию,
скопирует программу в `%LOCALAPPDATA%\MoyaMuzyka` и создаст ярлыки. После этого приложение запускается
двойным кликом по ярлыку, без Flutter и командной строки. Чтобы обновить программу после правок кода,
запустите скрипт снова (закрыв приложение). Удалить: удалите папку `%LOCALAPPDATA%\MoyaMuzyka` и два ярлыка.

Если установленная версия попросит токен еще раз, просто войдите заново.

## Часть 2. Получение токена

1. Войдите в Яндекс в браузере.
2. Откройте ссылку (она же показана на экране входа в приложении):
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
3. Разрешите доступ. В адресной строке появится `...#access_token=ВАШ_ТОКЕН&...`
4. Вставьте в приложение весь адрес или только токен.

Токен - это доступ к вашему аккаунту. Никому его не передавайте и не выкладывайте в репозиторий.
Приложение хранит его локально на устройстве (shared_preferences, без шифрования).
Client ID выше принадлежит официальному приложению Яндекс Музыки для Windows - его используют
сообщество и неофициальные библиотеки. Если Яндекс его закроет, способ перестанет работать.

## Часть 3. iOS

iOS-приложение собирается **только на Mac с Xcode**. На Windows его не собрать.

1. На Mac установите Xcode (из App Store), Flutter и CocoaPods (`sudo gem install cocoapods` или `brew install cocoapods`).
2. Повторите "Часть 1, шаг 2" на Mac (`flutter create ...`, `flutter pub get`).
3. В файле `ios/Podfile` раскомментируйте/измените первую строку: `platform :ios, '13.0'`.
4. `cd ios && pod install && cd ..`
5. Откройте `ios/Runner.xcworkspace` в Xcode → Runner → Signing & Capabilities → выберите свой Team
   (подойдет бесплатный Apple ID) и уникальный Bundle Identifier, например `com.qwer.ymusic`.
6. Подключите iPhone, включите на нем режим разработчика (Настройки → Конфиденциальность и безопасность),
   затем: `flutter run -d <id устройства>` (список: `flutter devices`).
7. Доверьте сертификат на телефоне: Настройки → Основные → VPN и управление устройством.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить. Для постоянной установки
и публикации нужна платная программа разработчика Apple ($99 в год).

Без Mac можно собирать в облаке (Codemagic, GitHub Actions на macOS), но подпись и установка все равно
потребуют Apple ID.

Игра в фоне на iOS (экран заблокирован) в этой версии не настроена: нужно добавить пакет `audio_service`
и `UIBackgroundModes → audio` в `Info.plist`. Это следующий шаг.

## Структура

| Файл | Что внутри |
|------|-----------|
| `lib/api.dart` | Запросы к API Яндекс Музыки, подпись ссылок на треки (**здесь чинить, если API изменится**) |
| `lib/player.dart` | Очередь и воспроизведение |
| `lib/screens.dart` | Все экраны: вход, треки, плейлисты, поиск, плеер |
| `lib/theme.dart` | Цвета и стиль (черный и серый) |
| `lib/models.dart` | Track, Playlist |
| `lib/main.dart` | Запуск, хранение токена |

## Если что-то не работает

- **401/403 или "Токен не подошел"** - получите токен заново.
- **Трек не играет, "нет доступных потоков"** - часть каталога доступна только с подпиской Плюс.
- **"Не удалось запустить волну"** - Яндекс перевел волну на новые "сессии", а формат запросов
  неофициальный. Текст ошибки показывается на вкладке "Моя волна". Правится в `lib/api.dart`, блок
  "Моя волна" (`waveStart`, `waveNext`, `waveFeedback`).
- **Ошибка при запросе ссылки на трек** - вероятнее всего, Яндекс изменил подпись или формат ответа
  `download-info`; правится в `streamUrl()` в `lib/api.dart`.
- **Ошибка сборки Windows про symlink** - не включен режим разработчика (шаг 4).

## Важно

Это неофициальный клиент. Используйте его со своим аккаунтом и подпиской и соблюдайте
условия использования Яндекс Музыки. Для публикации в App Store/Microsoft Store условия Яндекса
стоит перечитать отдельно.
